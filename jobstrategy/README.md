# Girish's Biopharma Job Search - Complete Tracking System

Welcome to your comprehensive job search tracking system! This folder contains everything you need to organize and manage Girish's job search for biopharma positions in New Jersey.

---

## 📁 File Overview

### 1. **Job_Applications_Tracker.csv**
**Purpose**: Main spreadsheet for tracking all job applications
- Open in Excel, Google Sheets, or Numbers
- Track application status, dates, contacts, and follow-ups
- Easy to filter and sort by company, status, or date

**How to Use**:
- Add a new row for each job you apply to
- Update status regularly: To Apply → Applied → Phone Screen → Interview → Offer/Rejected
- Set follow-up dates to remind yourself to check in

**How to Use**:
- Check daily for action items
- Update weekly goals every Monday

**How to Use**:
- Fill in research before applying to each company

## 🚀 Quick Start Guide

### Step 1: Set Up Job Alerts (Day 1)
Visit each company's career page and set up job alerts:
- [Pfizer](https://pfizer.wd1.myworkdayjobs.com/PfizerCareers)
- [Sanofi](https://jobs.sanofi.com/en/search-jobs)
- [Merck](https://jobs.merck.com/us/en/search-results)
- [J&J](https://jobs.jnj.com/)

**Search Keywords**: "Senior Scientist", "Process Development", "Downstream", "CPD", "Biologics"
**Location Filter**: New Jersey

### Step 2: Daily Routine (15-30 minutes)
1. Check job alerts from email
2. Search company career pages manually
3. Add interesting positions to the tracker
4. Apply to 1-2 positions (with customized resume/cover letter)

### Step 3: Weekly Review (Sunday evening)
1. Review Job_Search_Dashboard.md
2. Update application status in tracker
3. Set weekly goals
4. Follow up on applications from 1-2 weeks ago
5. Reach out to networking contacts

### Step 4: Before Each Interview
1. Review Company_Research_Notes.md for that company
2. Review Interview_Prep_Guide.md
3. Prepare 3-5 questions to ask
4. Practice STAR responses

## 💡 Pro Tips

### For Applications
1. **Customize each resume** - Highlight relevant experience for each role
2. **Use keywords from job description** - ATS (Applicant Tracking Systems) scan for these
3. **Apply early** - Within first 48 hours of posting increases chances
4. **Follow up** - Send a polite follow-up email after 1-2 weeks

### For Networking
1. **LinkedIn is key** - Connect with people at target companies
2. **Informational interviews** - Ask for 15-20 min calls to learn about roles
3. **Referrals matter** - Employee referrals significantly increase interview chances
4. **Professional associations** - Join ISPE, PDA, or similar biopharma groups

### For Interviews
1. **Research the interviewer** - Check their LinkedIn before the call
2. **Bring examples** - Have specific numbers and outcomes ready (STAR method)
3. **Ask smart questions** - Shows genuine interest and preparation
4. **Send thank you notes** - Within 24 hours, always

## 📊 Success Metrics to Track

- **Applications submitted per week**: Target 5-10
- **Response rate**: % of applications that get a response
- **Interview conversion**: % of responses that lead to interviews
- **Offer conversion**: % of final interviews that lead to offers

**Industry Average Benchmarks**:
- Response rate: 10-20%
- Interview rate: 5-15%
- Offer rate: 20-30% (after final interview)

This means you might need to apply to 50-100 positions to get 1-2 offers.
