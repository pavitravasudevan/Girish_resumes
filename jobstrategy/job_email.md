## 📧 Tier 1 Companies - Set Up First

### 1. Merck (MSD)

**URL**: https://jobs.merck.com/us/en/search-results

**Steps**:
1. Go to Merck careers site
2. Click **"Search Jobs"** or use the search bar
3. **Location**: Enter "New Jersey" or "Rahway" or "Kenilworth"
4. **Keywords**: Enter "Process Development" OR "Senior Scientist" OR "Downstream"
5. Click the **"Create Alert"** button (top right near search results)

## 📋 Email Management Tips

### Create Email Filter/Folder

To keep job alerts organized:

**Gmail**:
1. Settings → Filters and Blocked Addresses
2. Create filter for emails containing: "job alert" OR "talent community"
3. Apply label: "Job Alerts - Biopharma"
4. Mark as important (optional)

**Outlook**:
1. Rules → Create Rule
2. From addresses: careers@merck.com, jobs@jnj.com, etc.
3. Move to folder: "Job Alerts"

**Apple Mail**:
1. Mail → Preferences → Rules
2. Create rule for job alert emails
3. Move to mailbox: "Job Search"

## 🚨 Troubleshooting

### Not Receiving Alerts?

**Check**:
1. ✅ Spam/Junk folder - job alerts often go here initially
2. ✅ Email address was entered correctly
3. ✅ Alert is set to "Daily" not "Weekly"
4. ✅ Alert is "Active" (check your job alert settings)

**Fix**:
- Mark job alert emails as "Not Spam"
- Add sender to contacts
- Check "Promotions" tab in Gmail

### Too Many Alerts?

**Adjust**:
- Change frequency from Daily to Weekly
- Make search more specific (add more keywords)
- Reduce number of alerts (keep only top priority companies)

### No Jobs Matching Criteria?

**Expand search**:
- Remove location filter (search all US)
- Use broader keywords ("Scientist" instead of "Process Development Scientist")
- Add "Remote" as location option
- Include nearby states (NY, PA, CT, DE)
